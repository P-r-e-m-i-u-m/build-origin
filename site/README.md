# Build Origin Site

The tiny website for [Build Origin](https://github.com/P-r-e-m-i-u-m/build-origin).

No framework. No dependency maze. Just HTML and CSS.

## Files

- `index.html` - the page
- `style.css` - the whole look

Open `index.html` directly in a browser to see it.

## Why so simple?

Because this is a small repo site, not a reason to install 47 packages.

Change the copy. Change the CSS. Break it. Fix it. Make it yours.

Built one commit at a time.
